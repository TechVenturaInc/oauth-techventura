Privacy Policy — schada-gws

Last updated: 6 September 2026

Who this is for

schada-gws ("the app") is a personal, single-user tool operated by the developer for their own Google account. It is not offered to, or usable by, other people.

What it accesses

With the account owner's explicit OAuth consent, the app requests read-only access to Google Workspace data — Gmail messages, and if later enabled, Calendar, Drive, and Docs — solely to produce personal summaries and digests for the account owner.

How data is handled

The app runs locally on the account owner's own computer. OAuth tokens are stored in the operating system keychain or a local encrypted file on that computer. Message content is processed locally and transiently to build a digest; it is not uploaded to any external server operated by the developer, and no database of message content is retained.

Sharing

No data is sold, rented, or shared with any third party. There is no advertising, and no analytics or tracking.

Google user data — Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

No Google user data is retained beyond the local processing described above. The account owner can revoke the app's access at any time at myaccount.google.com/permissions, which immediately ends all access.
